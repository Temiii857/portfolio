Website Reflection

A reflection on building portfolio websites with GitHub Pages and WordPress, and how this process helped me grow as a designer.

Overview

Building websites with GitHub Pages and WordPress helped me understand how different platforms can shape the design process. Both tools have strengths and limitations, and the best choice depends on the goals of the project.

This experience helped me think more about usability, customization, layout choices, and how design decisions affect the way users interact with a website.

Challenges for New Learners

GitHub Pages: GitHub Pages was more difficult to learn at first because it requires knowledge of HTML, CSS, Git, and repositories. Editing the design directly through code felt challenging, but it also gave me more control over the final website.

WordPress: WordPress was easier to start with because it uses themes, templates, and visual editing tools. However, it became frustrating when I wanted to make more specific design changes that were limited by the template.

Advantages

GitHub Pages: The biggest advantage of GitHub Pages is creative control. I was able to customize the structure, layout, and style of my website using code. This helped me strengthen my web design skills and better understand how websites are built.

WordPress: WordPress is useful for creating a website quickly. It can be helpful for people who want a professional-looking site without needing to code everything from scratch.

Connection to UI/UX and Human Factors

This project connects to UI/UX design because I had to think about how users would move through the site, read information, and understand the layout. Navigation, spacing, readability, and visual hierarchy all affected the overall user experience.

My Human Factors background also helped me think about usability and accessibility. I wanted the site to feel clear, organized, and easy to navigate so users could find information without confusion.

Skills I Want to Improve

I want to continue improving my CSS skills so I can create stronger layouts and more polished visual designs. I also want to learn more JavaScript so I can add interactive elements that make websites feel more engaging and modern.

As I continue building my portfolio, I want my work to show growth in UI/UX design, product design, accessibility, and user-centered thinking.

Final Thoughts

Overall, I prefer GitHub Pages because it gives me more control and allows me to design a website more intentionally. WordPress is useful for fast website building, but GitHub Pages feels like a better fit for the kind of creative and technical work I want to keep developing.

This project helped me better understand the connection between design, technology, and user experience. It also showed me how much I enjoy creating digital products that are both functional and visually engaging.
